# Open on your phone with GitHub Pages

This project is ready to host under a GitHub Pages repository URL; asset paths, PWA scope and service worker URLs are relative.

1. Upload the project source to a GitHub repository, retaining `dist/` and `.github/workflows/pages.yml`.
2. In the repository choose Settings → Pages → Source → GitHub Actions.
3. Run the Publish Hoek Studio workflow manually.
4. Open the resulting Pages HTTPS URL on your phone.
5. Choose one of the five starting themes. Wait for offline preparation, then add to your home screen from Safari or Chrome.

No local computer or Node.js server is required for use after publication. The browser stores your edits locally; GitHub hosts the initial app and its bundled toolbar metadata. Ordinary GitHub Pages sites are publicly accessible, including bundled source metadata and icons. Publishing to a public repository also makes its source public. Obtain the owner's approval for public exposure before enabling Pages; a private repository alone does not guarantee a private Pages website.

The repository workflow is prepared but preparing these files does not upload them or enable Pages. See the actual deployment result for the live URL.
